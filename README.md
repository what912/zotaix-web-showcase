## 项目概览

ZOTAIX 将自然语言需求、产品方向、瓶器形体及材质预览组织到同一创作流程中，面向个人礼赠、品牌联名和企业定制场景。

| 界面 | 展示内容 |
| --- | --- |
| 首页 | 项目定位、作品展示和创作入口 |
| AI 助手 | 文字需求输入、对话入口和创作方向提示 |
| 共创工作台 | 3D 概念轮廓、形体参数及材质调整入口 |
| 手机版 | 适配手机屏幕的首页布局 |

以下截图来自项目的本地演示模式。它们展示界面和交互入口，不代表在线 AI、支付或云端保存服务已经完成配置。概念模型不等于可生产的实物方案。
